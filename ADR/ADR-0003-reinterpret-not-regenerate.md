# ADR-0003：知识必须可以重新理解，而不是重新生成

- 状态：Accepted
- 日期：2026-07-27

## 决策

Knowledge 层只保存**原始事实**（原文片段、出处、忠于原文的事实表述），不保存 AI 结论。AI 的总结、观点、草稿一律属于 Reasoning 层的派生数据，随时可以整体删除、用新模型重新推理。

## 背景

如果系统保存的是「AI 总结」，那么每次模型升级都要重新 OCR、重新 Prompt、重新总结——知识没有沉淀。正确的方式是：

```
Knowledge（原始事实，永存） → 重新推理 → 新的观点（随时可再生）
```

一年后 GPT-7 出来，不重新生成任何 Knowledge，只对它做更好的重新理解。

## 后果

- fragment 表中的原文一字不改、永不删除。
- knowledge 表的判别标准：任何一行在模型升级后都**不需要重新生成**；做不到的字段属于 Reasoning 层，不得进入 Knowledge 层建模。
- Reasoning 层的派生表必须可整体 TRUNCATE 重建，且记录推理依据（knowledge_ids、model、prompt_version）。
- 知识入库前必须经作者 Approve（见 ADR-0004）——人的判断是资产的一部分，永不自动化。

## 违规判定

任何把模型输出直接写入 knowledge/fragment、或删改原文的代码，直接打回。
