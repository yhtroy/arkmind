# Knowledge Examples（Canon v0.1）

- 状态：**Draft** —— 与 [knowledge_rules.md](knowledge_rules.md) 配套，M1.1 用真实书页校准后定稿
- **本文件全部为 `Example (Synthetic)`**：下列原文为演示规则而编写的示意文本（风格参照常见心理/自助类书籍的龙虾、血清素、站姿段落），不代表任何具体书页。Gold Standard 定稿时必须全部替换为 `Example (Verified)`（见 rules 「示例标注约定」）。
- 每个案例格式：原文 → 提取 → 判定依据。

---

## 第一部分：10 个正确提取案例 ✅

### C1 — Definition 成条（Rule 1 / Rule 8）

- 原文：「血清素是一种神经递质。」
- 提取：`definition`｜血清素是一种神经递质。
- 依据：原文给概念下了定义，Concept 被赋予性质后成条。忠于原文，未升华。

### C2 — 一个 Evidence 一条（Rule 2）

- 原文：「龙虾在打斗失败后，体内血清素水平会下降。」
- 提取：`evidence`｜龙虾打斗失败后血清素水平下降。
- 依据：一个主体（失败的龙虾）+ 一个结果（血清素下降）= 一条。

### C3 — 同一实验两个结果，拆成两条（Rule 2 / Rule 5）

- 原文：「失败的龙虾血清素下降，同时章鱼胺上升。」
- 提取：
  - `evidence`｜失败的龙虾血清素下降。
  - `evidence`｜失败的龙虾章鱼胺上升。
- 依据：两个可独立核验的现象，各自成条，不合并。

### C4 — 指令句归 Quote/Evidence，不是 Action（Rule 4）

- 原文：「站直，把肩膀打开。」
- 提取：`quote`｜“站直，把肩膀打开。”
- 依据：这是作者陈述的内容，原样保留为 Quote。不拆成 `action`（kind 无 action），也不提炼成“保持自信”——那属于 Reasoning 层。

### C5 — 因果拆分（Rule 5）

- 原文：「因为失败的龙虾血清素下降，所以它更容易蜷缩、逃避。」
- 提取：
  - `evidence`｜失败的龙虾血清素下降。
  - `evidence`｜失败的龙虾更容易蜷缩、逃避。
- 依据：`因为…所以…` 必须拆。因果关系本身不建模（Relation 在"明确不建模"清单）。

### C6 — Quote 原样保留（Rule 3）

- 原文：「作者写道：“站直，昂首挺胸。”」
- 提取：`quote`｜“站直，昂首挺胸。”
- 依据：原样引用、一字不改，且表达一个完整意思。

### C7 — Data 成条（Rule 2）

- 原文：「龙虾在地球上已经存在了约 3.5 亿年。」
- 提取：`data`｜龙虾存在约 3.5 亿年。
- 依据：一个可核验的数据点成条，数字忠于原文。

### C8 — 保留原文强度限定词（Rule 6）

- 原文：「昂首挺胸的姿势可能有助于提升自信。」
- 提取：`evidence`｜昂首挺胸的姿势可能有助于提升自信。
- 依据：保留「可能」这一强度限定，不改写成「能提升」。

### C9 — 性质陈述成条（Rule 1 / Rule 8）

- 原文：「血清素影响个体的姿态与情绪。」
- 提取：`definition`｜血清素影响个体的姿态与情绪。
- 依据：原文赋予概念以作用/角色，成条；未添加原文外的机制解释。

### C10 — 主体明确的观察成条（Rule 2）

- 原文：「获胜的龙虾会占据最好的庇护所。」
- 提取：`evidence`｜获胜的龙虾占据最好的庇护所。
- 依据：主体 + 行为，可对照原文核验。

## 第二部分：10 个错误提取案例 ❌

### E1 — 升华：加入了原文没有的道理（Rule 6）

- 原文：「站直，把肩膀打开。」
- 错误提取：`evidence`｜站直能使人保持自信。
- 为什么错：原文只讲身体姿势，没有「保持自信」。这句"没有错"，但不是原文事实 → Knowledge Fidelity 下降。（行动建议属 Reasoning 层，不入库。）

### E2 — 混入外部知识（Rule 6）

- 原文：「血清素是一种神经递质。」
- 错误提取：`definition`｜血清素由色氨酸合成，缺乏会导致抑郁。
- 为什么错：合成路径与抑郁结论来自外部知识，原文没写。

### E3 — 强度失真（Rule 6）

- 原文：「昂首挺胸可能有助于提升自信。」
- 错误提取：`evidence`｜昂首挺胸能显著提升自信。
- 为什么错：把「可能有助于」改成「能显著」，改变了原文强度。

### E4 — 跨段归纳总结（Rule 10）

- 原文（整节讲龙虾等级）：……
- 错误提取：`definition`｜本章告诉我们要勇敢面对竞争。
- 为什么错：这是跨段概括，属于 Reasoning 层的理解，写入 Knowledge 即污染。

### E5 — 裸概念（Rule 8）

- 原文：「……血清素……」
- 错误提取：`concept`｜血清素。
- 为什么错：孤立名词不含事实，原文未在此处赋予其定义或性质。

### E6 — 提取修辞/比喻（Rule 9）

- 原文：「你不是龙虾，但你的大脑里也住着一只古老的龙虾。」
- 错误提取：`evidence`｜人脑里住着一只龙虾。
- 为什么错：这是比喻修辞，不是事实陈述。

### E7 — 混合未拆（Rule 5）

- 原文：「失败的龙虾血清素下降，所以更容易逃避。」
- 错误提取：`evidence`｜血清素下降导致龙虾逃避，说明失败者难翻身。
- 为什么错：一条里塞了因果 + 引申结论，既没拆又升华。

### E8 — Quote 被改写（Rule 3）

- 原文：「作者写道：“站直，昂首挺胸。”」
- 错误提取：`quote`｜作者建议我们挺胸抬头、充满自信地生活。
- 为什么错：quote 必须一字不改，这里是转述+升华。

### E9 — 无出处（Rule 7）

- 原文：「龙虾存在约 3.5 亿年。」
- 错误提取：`data`｜龙虾存在约 3.5 亿年。（无 provenance / 无页码）
- 为什么错：缺出处，无法回链核验，直接打回，不进入人工评审。

### E10 — 情绪/过渡语（Rule 9）

- 原文：「说实话，这一点让我非常震惊。接下来我们看……」
- 错误提取：`evidence`｜作者对龙虾研究感到震惊。
- 为什么错：作者情绪与过渡语不是可积累的知识事实。
